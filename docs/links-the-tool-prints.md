# Links the tool prints

The web addresses that the released files can show a user: in a command's output, in a rule page, in the Action's summary or
in a document. It is generated when the release is built, so an address cannot be added without appearing here, and the
build's tests fail when one does.

This page is the list a maintainer opens by hand before a release: for an address, check that the page exists and says what the
text around it says. Hosts that only stand for an example, such as `example.com` and `localhost`, are not listed.

The rule pages and the output of `explain`, `scan`, `score`, `gain` and `up` hold no link to a page on a website that this
repository cannot show exists. What is listed is the repository itself, the registries and standards the text names, the
public repositories the precision run measures, and the documents' own links.
