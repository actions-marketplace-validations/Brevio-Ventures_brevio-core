# R3.4: Pre-execution quota enforcement

**Short answer:** Verify tier entitlement before paid LLM/API calls. A paid call made before the entitlement check costs money for a customer who may not use it.

Group: Billing and money. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Pre-execution quota enforcement: verify tier entitlement before paid LLM/API calls.

## Why

A paid call made before the entitlement check costs money for a customer who may not use it.

## How to silence it

A person can silence one finding with `brevio-core: ignore R3.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
