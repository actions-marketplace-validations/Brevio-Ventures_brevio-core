# R8.1: Anti-cloaking & markdown parity

**Short answer:** Serve identical facts to crawlers and browsers. Showing a crawler different facts than a person is cloaking. Search engines penalise it.

Group: Marketing and attribution. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Anti-cloaking & markdown parity: serve identical facts to crawlers and browsers.

## Why

Showing a crawler different facts than a person is cloaking. Search engines penalise it.

## A bad example

```ts
if (isBot(ua)) return richPage; else return thinPage;
```

## A good example

```ts
return samePage;
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R8.1 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
