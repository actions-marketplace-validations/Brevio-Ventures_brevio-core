# R13.3: Trace context propagation

**Short answer:** Distributed calls forward traceparent / correlation IDs. Without the trace id you cannot follow one request across services.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Trace context propagation: distributed calls forward traceparent / correlation IDs.

## Why

Without the trace id you cannot follow one request across services.

## A bad example

```ts
await fetch(url);
```

## A good example

```ts
await fetch(url, { headers: { traceparent } });
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R13.3 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
