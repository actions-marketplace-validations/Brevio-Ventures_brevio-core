# R16.8: Deterministic engine constraints

**Short answer:** Package.json specifies minimum node/pnpm engines. Without an engines field, someone installs with a Node that cannot run the code.

Group: Supply chain. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Deterministic engine constraints: package.json specifies minimum node/pnpm engines.

## Why

Without an engines field, someone installs with a Node that cannot run the code.

## A bad example

```json
{ "name": "app" }
```

## A good example

```json
{ "name": "app", "engines": { "node": ">=20", "pnpm": ">=9" } }
```
