# R13.2: Structured JSON logging

**Short answer:** Application logs emit valid JSON key-value pairs with timestamps. Plain text logs cannot be searched by field.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Structured JSON logging: application logs emit valid JSON key-value pairs with timestamps.

## Why

Plain text logs cannot be searched by field.

## A bad example

```ts
console.log('user ' + id + ' failed');
```

## A good example

```ts
log.info({ event: 'login.failed', userId: id });
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R13.2 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
