# R7.4: Acyclic module layering

**Short answer:** Domain -> application -> adapters; no circular imports. A cycle between layers means none of them can be tested or changed alone.

Group: Architecture and contracts. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Acyclic module layering: domain -> application -> adapters; no circular imports.

## Why

A cycle between layers means none of them can be tested or changed alone.

## A bad example

```
adapters/db.ts imports domain/order.ts, and domain/order.ts imports adapters/db.ts
```

## A good example

```
adapters/db.ts imports domain/order.ts only
```
