# R14.4: CSRF token validation

**Short answer:** State-changing forms and endpoints validate anti-CSRF token. Without a token another site can submit your user's form for them.

Group: Auth and sessions. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

CSRF token validation: state-changing forms and endpoints validate anti-CSRF token.

## Why

Without a token another site can submit your user's form for them.

## A bad example

```html
<form method="post" action="/transfer">
```

## A good example

```html
<form method="post" action="/transfer">
  <input type="hidden" name="csrf" value={token} />
```
