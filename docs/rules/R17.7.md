# R17.7: Server action security

**Short answer:** Server actions validate session authentication before mutating. A server action is a public endpoint. Anyone can call it.

Group: React and Next.js patterns. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Server action security: server actions validate session authentication before mutating.

## Why

A server action is a public endpoint. Anyone can call it.

## A bad example

```tsx
'use server';
export async function remove(id) { await db.delete(id); }
```

## A good example

```tsx
'use server';
export async function remove(id) { await requireSession(); await db.delete(id); }
```
