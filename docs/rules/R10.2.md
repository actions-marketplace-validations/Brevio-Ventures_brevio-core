# R10.2: Idempotency key transmission

**Short answer:** Mutating external POST/PUT requests send Idempotency-Key. Without an idempotency key a retried POST creates the thing twice.

Group: API and network robustness. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Idempotency key transmission: mutating external POST/PUT requests send Idempotency-Key.

## Why

Without an idempotency key a retried POST creates the thing twice.

## A bad example

```ts
await fetch(url, { method: 'POST', body });
```

## A good example

```ts
await fetch(url, { method: 'POST', body, headers: { 'Idempotency-Key': key } });
```
