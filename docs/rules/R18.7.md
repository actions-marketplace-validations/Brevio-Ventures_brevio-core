# R18.7: Visible focus rings

**Short answer:** Interactive elements retain visible focus outline for keyboard users. People who use a keyboard need to see where the focus is.

Group: Accessibility (WCAG 2.1 AA). Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Visible focus rings: interactive elements retain visible focus outline for keyboard users.

## Why

People who use a keyboard need to see where the focus is.

## A bad example

```css
button:focus { outline: none; }
```

## A good example

```css
button:focus-visible { outline: 2px solid #1a73e8; }
```
