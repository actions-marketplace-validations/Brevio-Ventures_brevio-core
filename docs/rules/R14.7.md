# R14.7: Brute-force throttle

**Short answer:** Login and reset-password routes rate-limited by IP and username. Without a limit, a script can try a million passwords.

Group: Auth and sessions. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Brute-force throttle: login and reset-password routes rate-limited by IP and username.

## Why

Without a limit, a script can try a million passwords.

## A bad example

```ts
app.post('/login', login);
```

## A good example

```ts
app.post('/login', rateLimit({ perIp: 10, perUser: 5 }), login);
```
