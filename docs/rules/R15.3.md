# R15.3: Form submit recovery

**Short answer:** Failed form submission preserves user input for retry. A form that clears on failure makes people retype everything.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Form submit recovery: failed form submission preserves user input for retry.

## Why

A form that clears on failure makes people retype everything.

## A bad example

```ts
onError: () => form.reset()
```

## A good example

```ts
onError: (e) => setErrors(e.fields)  // values stay
```
