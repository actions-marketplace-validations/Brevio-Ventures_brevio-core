# R20.5: No empty test block

**Short answer:** A test whose body is empty, `pass` or `...` tests nothing. A test with an empty body passes without checking anything, and still counts as a test.

Group: Test custody. Status: preview. New, and not measured on any code yet. A finding is a prompt for a reviewer, not proof of a problem: a change can drop or rewrite a test for a good reason. `brevio-core scan` does not run this rule, so no scan fails on it. `brevio-core check` reports it and exits 1 when it does. Generated from the rule definitions; do not edit by hand.

## What it catches

No empty test block: a test whose body is empty, `pass` or `...` tests nothing.

## Why

A test with an empty body passes without checking anything, and still counts as a test.

## A bad example

```
it('charges the card', () => {});
```

## A good example

```
// give the test a body that checks something:
it('charges the card', () => {
  expect(charge(card)).toBe('ok');
});
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R20.5 -- reason` on the line or the line above, in `brevio-core check`. Without the reason it does not count. A setting in `brevio-core.toml` does not turn it off.

What the check already leaves alone: a Python test function whose body is only pass, a docstring or `...`, and a JavaScript or TypeScript it or test with an empty body on one line, are flagged; comment lines are not.

To change what the rule flags, edit its check in `gates/core_gates.py`. That is a code change and is reviewed like one.
