# R17.5: Next/Font optimization

**Short answer:** Load Google or local fonts via next/font to avoid layout shift. A font loaded by link shifts the text when it arrives.

Group: React and Next.js patterns. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Next/Font optimization: load Google or local fonts via next/font to avoid layout shift.

## Why

A font loaded by link shifts the text when it arrives.

## A bad example

```tsx
<link href="//fonts.googleapis.com/css2?family=Inter" rel="stylesheet" />
```

## A good example

```tsx
const inter = Inter({ subsets: ['latin'] });  // next/font
```
