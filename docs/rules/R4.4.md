# R4.4: Ingestion FK pre-resolution

**Short answer:** Upsert or verify parent workspace before child rows. A child row inserted before its parent exists fails, or points at nothing.

Group: Database and migrations. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Ingestion FK pre-resolution: upsert or verify parent workspace before child rows.

## Why

A child row inserted before its parent exists fails, or points at nothing.

## A bad example

```ts
await db.insert(event);
```

## A good example

```ts
await upsertWorkspace(event.workspaceId);
await db.insert(event);
```

## How it is checked

- `brevio-core brief` and the `brief` tool of `brevio-core mcp` print a one-line reminder of it for a file that matches.

## How to silence it

A person can silence one finding with `brevio-core: ignore R4.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
