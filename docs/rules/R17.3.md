# R17.3: Metadata API compliance

**Short answer:** Route pages export static or generateMetadata for SEO. A page with no metadata has no title or description in search results.

Group: React and Next.js patterns. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Metadata API compliance: route pages export static or generateMetadata for SEO.

## Why

A page with no metadata has no title or description in search results.

## A bad example

```tsx
export default function Page() {}
```

## A good example

```tsx
export const metadata = { title: 'Pricing', description: 'Plans and prices' };
```

- Nothing yet. No `brevio-core` command checks it and no `brief` reminder names it: it is a standing rule for authors and reviewers.

## How to silence it

A person can silence one finding with `brevio-core: ignore R17.3 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
