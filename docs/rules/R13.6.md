# R13.6: Audit event journaling

**Short answer:** Security-critical actions append an immutable audit record. Without an audit record you cannot say who changed a role or a key.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Audit event journaling: security-critical actions append an immutable audit record.

## Why

Without an audit record you cannot say who changed a role or a key.

## A bad example

```ts
await setRole(user, 'admin');
```

## A good example

```ts
await setRole(user, 'admin');
await audit.append({ actor, action: 'role.set', target: user });
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R13.6 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
