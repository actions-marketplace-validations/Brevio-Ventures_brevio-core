# R19.2: Cyclomatic complexity bounding

**Short answer:** Functions maintain cyclomatic complexity <= 20. Many branches in one function means many cases nobody tests.

Group: Clean code. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Cyclomatic complexity bounding: functions maintain cyclomatic complexity <= 20.

## Why

Many branches in one function means many cases nobody tests.

## A bad example

```py
if a: ... elif b: ... elif c: ... # 25 branches
```

## A good example

```py
table = {a: fa, b: fb, c: fc}
return table[key]()
```
