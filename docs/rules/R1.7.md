# R1.7: LCP asset priority

**Short answer:** Priority/fetchpriority=high on hero LCP image, lazy below fold. The browser cannot know the hero image is the largest paint unless you say so.

Group: UI and mobile performance. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

## How to silence it

A person can silence one finding with `brevio-core: ignore R1.7 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
