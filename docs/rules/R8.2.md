# R8.2: Honest telemetry attribution

**Short answer:** Label synthetic or demo data and keep it apart from live metrics. Demo numbers mixed into live numbers make every report untrue.

Group: Marketing and attribution. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Honest telemetry attribution: label synthetic or demo data and keep it apart from live metrics.

## Why

Demo numbers mixed into live numbers make every report untrue.

## A bad example

```ts
metrics.push(...demoRows, ...liveRows)
```

## A good example

```ts
metrics.push(...liveRows)  // demo rows are labelled and kept apart
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R8.2 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
