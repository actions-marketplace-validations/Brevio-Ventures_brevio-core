# R15.4: Image broken state fallback

**Short answer:** Img / Image tags provide alt and error state fallback. A broken image with no fallback leaves a hole in the layout.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Image broken state fallback: img / Image tags provide alt and error state fallback.

## Why

A broken image with no fallback leaves a hole in the layout.

## A bad example

```tsx
<img src={url} alt="" />
```

## A good example

```tsx
<img src={url} alt="Team photo" onError={useFallback} />
```
