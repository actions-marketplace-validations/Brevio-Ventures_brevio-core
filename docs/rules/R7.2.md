# R7.2: Granular field validation

**Short answer:** Return field-level errors and preserve user form inputs. One generic error forces the user to guess and to retype the whole form.

Group: Architecture and contracts. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Granular field validation: return field-level errors and preserve user form inputs.

## Why

One generic error forces the user to guess and to retype the whole form.

## A bad example

```ts
return { error: 'invalid' };
```

## A good example

```ts
return { errors: { email: 'Enter a valid email' } };
```
