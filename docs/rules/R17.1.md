# R17.1: Server Component default

**Short answer:** Components in app directory default to RSC unless 'use client'. A Server Component sends no JavaScript for itself. A client one does.

Group: React and Next.js patterns. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Server Component default: components in app directory default to RSC unless 'use client'.

## Why

A Server Component sends no JavaScript for itself. A client one does.

## A bad example

```tsx
'use client';  // on a page that only renders text
```

## A good example

```tsx
// no directive: a Server Component
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R17.1 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
