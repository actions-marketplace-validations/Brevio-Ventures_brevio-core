# R16.4: No install script execution

**Short answer:** Untrusted packages ignore postinstall lifecycle scripts. An install script runs code from a package you have not read.

Group: Supply chain. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

No install script execution: untrusted packages ignore postinstall lifecycle scripts.

## Why

An install script runs code from a package you have not read.

## A bad example

```
pnpm install
```

## A good example

```
pnpm install --ignore-scripts
```

## How it is checked

- Nothing yet. No `brevio-core` command checks it and no `brief` reminder names it: it is a standing rule for authors and reviewers.

Not measured. No judged sample of this rule's hits exists.

## How to silence it

A person can silence one finding with `brevio-core: ignore R16.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
