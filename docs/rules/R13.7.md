# R13.7: Health check hermeticity

**Short answer:** /healthz endpoints execute lightweight non-allocating probes. A heavy health check can take the service down when it is probed often.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Health check hermeticity: /healthz endpoints execute lightweight non-allocating probes.

## Why

A heavy health check can take the service down when it is probed often.

## A bad example

```ts
app.get('/healthz', async () => await db.query('SELECT count(*) FROM orders'));
```

## A good example

```ts
app.get('/healthz', () => ({ ok: true }));
```
