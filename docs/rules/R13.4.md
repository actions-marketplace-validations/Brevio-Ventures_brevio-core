# R13.4: Metric label cardinality bounding

**Short answer:** Avoid dynamic user IDs or timestamps in metric labels. A user id as a metric label creates a new time series per user and floods the store.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Metric label cardinality bounding: avoid dynamic user IDs or timestamps in metric labels.

## Why

A user id as a metric label creates a new time series per user and floods the store.

## A bad example

```ts
counter.inc({ userId });
```

## A good example

```ts
counter.inc({ route });
```
