# R10.8: Strict HTTP verb mapping

**Short answer:** GET requests are read-only and free of side effects. A GET that changes data is triggered by crawlers, prefetchers and link previews.

Group: API and network robustness. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Strict HTTP verb mapping: GET requests are read-only and free of side effects.

## Why

A GET that changes data is triggered by crawlers, prefetchers and link previews.

## A bad example

```ts
app.get('/delete/:id', remove);
```

## A good example

```ts
app.delete('/items/:id', remove);
```
