# R2.7: Secure cookie & CORS hygiene

**Short answer:** HttpOnly, Secure, SameSite, no wildcard CORS with credentials. A cookie without these flags can be read by scripts or sent from another site.

Group: Security and tenancy. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Secure cookie & CORS hygiene: HttpOnly, Secure, SameSite, no wildcard CORS with credentials.

## Why

A cookie without these flags can be read by scripts or sent from another site.

## A bad example

```ts
res.cookie('sid', id);
```

## A good example

```ts
res.cookie('sid', id, { httpOnly: true, secure: true, sameSite: 'lax' });
```

## How it is checked

- `brevio-core brief` and the `brief` tool of `brevio-core mcp` print a one-line reminder of it for a file that matches.

Not measured. No judged sample of this rule's hits exists.

## How to silence it

A person can silence one finding with `brevio-core: ignore R2.7 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
