# R15.2: Non-blocking third-party failures

**Short answer:** External widgets render graceful placeholder on failure. If a chat widget fails to load, the rest of the page must still work.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Non-blocking third-party failures: external widgets render graceful placeholder on failure.

## Why

If a chat widget fails to load, the rest of the page must still work.

## A bad example

```tsx
<ChatWidget />
```

## A good example

```tsx
<ErrorBoundary fallback={null}><ChatWidget /></ErrorBoundary>
```
