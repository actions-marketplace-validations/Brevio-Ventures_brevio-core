# R1.3: Third-party script deferral

**Short answer:** Load GTM/GA4 with lazyOnload after hydration. A synchronous analytics tag blocks hydration, so the page feels slow on a phone.

Group: UI and mobile performance. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Third-party script deferral: load GTM/GA4 with lazyOnload after hydration.

## Why

A synchronous analytics tag blocks hydration, so the page feels slow on a phone.

## A bad example

```tsx
<script async src="//www.googletagmanager.com/gtag/js?id=G-1"></script>
```

## A good example

```tsx
<Script strategy="lazyOnload" src="//www.googletagmanager.com/gtag/js?id=G-1" />
```

- `brevio-core scan --surface` checks the lines you add for it; a plain `brevio-core scan` does not.
- `brevio-core brief` and the `brief` tool of `brevio-core mcp` print a one-line reminder of it for a file that matches.

## How to silence it

A person can silence one finding with `brevio-core: ignore R1.3 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
