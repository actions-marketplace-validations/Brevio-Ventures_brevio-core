# R12.5: Database connection pool hygiene

**Short answer:** Acquired pool clients release in finally blocks. A pool client that is not released starves the pool, and the app stops answering.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Database connection pool hygiene: acquired pool clients release in finally blocks.

## Why

A pool client that is not released starves the pool, and the app stops answering.

## A bad example

```ts
const c = await pool.connect(); await c.query(q);
```

## A good example

```ts
const c = await pool.connect();
try { await c.query(q); } finally { c.release(); }
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R12.5 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
