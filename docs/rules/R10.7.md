# R10.7: No unauthenticated admin endpoints

**Short answer:** Route middleware protects management routes. An admin route without a guard is open to the whole internet.

Group: API and network robustness. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

No unauthenticated admin endpoints: route middleware protects management routes.

## Why

An admin route without a guard is open to the whole internet.

## A bad example

```ts
app.post('/admin/reset', reset);
```

## A good example

```ts
app.post('/admin/reset', requireAdmin, reset);
```

- Nothing yet. No `brevio-core` command checks it and no `brief` reminder names it: it is a standing rule for authors and reviewers.

## How to silence it

A person can silence one finding with `brevio-core: ignore R10.7 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
