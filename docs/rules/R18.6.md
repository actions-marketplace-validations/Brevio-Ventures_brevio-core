# R18.6: Aria attributes validity

**Short answer:** Aria-* attributes use valid names and permissible state values. An invalid aria attribute is ignored, so the control has no name.

Group: Accessibility (WCAG 2.1 AA). Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Aria attributes validity: aria-* attributes use valid names and permissible state values.

## Why

An invalid aria attribute is ignored, so the control has no name.

## A bad example

```tsx
<div aria-lable="Close" />
```

## A good example

```tsx
<div aria-label="Close" />
```
