# R15.5: Network offline banner

**Short answer:** Offline connectivity state indicated with non-blocking alert. A user offline sees buttons that silently do nothing.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Network offline banner: offline connectivity state indicated with non-blocking alert.

## Why

A user offline sees buttons that silently do nothing.

## A bad example

```tsx
// no offline state
```

## A good example

```tsx
{!online && <Banner>You are offline. Changes will sync later.</Banner>}
```
