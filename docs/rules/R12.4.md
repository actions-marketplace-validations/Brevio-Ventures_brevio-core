# R12.4: WebSocket cleanup

**Short answer:** Client socket connections explicitly disconnect on navigation/unmount. A socket left open after navigation holds a connection and keeps receiving messages.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

WebSocket cleanup: client socket connections explicitly disconnect on navigation/unmount.

## Why

A socket left open after navigation holds a connection and keeps receiving messages.

## A bad example

```ts
const ws = new WebSocket(url);
```

## A good example

```ts
const ws = new WebSocket(url);
// on unmount: ws.close();
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R12.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
