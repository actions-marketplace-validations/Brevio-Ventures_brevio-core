# R8.3: Consent Mode v2 ordering

**Short answer:** Initialize default denied consent before analytics tags. An analytics tag that runs before consent is set breaks consent law.

Group: Marketing and attribution. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Consent Mode v2 ordering: initialize default denied consent before analytics tags.

## Why

An analytics tag that runs before consent is set breaks consent law.

## A bad example

```ts
gtag('config', 'G-1');
gtag('consent', 'default', { analytics_storage: 'denied' });
```

## A good example

```ts
gtag('consent', 'default', { analytics_storage: 'denied' });
gtag('config', 'G-1');
```
