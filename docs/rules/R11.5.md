# R11.5: Cache key stability

**Short answer:** Cache keys use sorted/normalized parameters to avoid fragmentation. Keys built from unsorted parameters make the same query miss the cache.

Group: State and concurrency. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Cache key stability: cache keys use sorted/normalized parameters to avoid fragmentation.

## Why

Keys built from unsorted parameters make the same query miss the cache.

## A bad example

```ts
const key = JSON.stringify(params);
```

## A good example

```ts
const key = JSON.stringify(Object.entries(params).sort());
```
