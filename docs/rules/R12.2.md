# R12.2: Timer lifecycle cleanup

**Short answer:** SetTimeout and setInterval handle IDs cleaned on component unmount. A timer that outlives its component updates state that no longer exists.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Timer lifecycle cleanup: setTimeout and setInterval handle IDs cleaned on component unmount.

## Why

A timer that outlives its component updates state that no longer exists.

## A bad example

```ts
useEffect(() => { setTimeout(f, 5000); }, []);
```

## A good example

```ts
useEffect(() => { const t = setTimeout(f, 5000); return () => clearTimeout(t); }, []);
```
