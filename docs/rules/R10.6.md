# R10.6: Content-Type negotiation

**Short answer:** Validate incoming request Accept / Content-Type headers. A handler that accepts any Content-Type may parse data it was never meant to.

Group: API and network robustness. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Content-Type negotiation: validate incoming request Accept / Content-Type headers.

## Why

A handler that accepts any Content-Type may parse data it was never meant to.

## A bad example

```ts
const body = await req.json();
```

## A good example

```ts
if (req.headers.get('content-type') !== 'application/json') return unsupported();
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R10.6 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
