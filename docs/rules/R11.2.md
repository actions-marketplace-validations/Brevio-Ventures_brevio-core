# R11.2: No dangling unawaited promises

**Short answer:** Promise chains either return or await explicitly. A promise nobody awaits fails with no one listening.

Group: State and concurrency. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

No dangling unawaited promises: promise chains either return or await explicitly.

## Why

A promise nobody awaits fails with no one listening.

## A bad example

```ts
save();
```

## A good example

```ts
await save();
```

- Nothing yet. No `brevio-core` command checks it and no `brief` reminder names it: it is a standing rule for authors and reviewers.

## How to silence it

A person can silence one finding with `brevio-core: ignore R11.2 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
