# R19.1: Function length limit

**Short answer:** Functions remain under 100 lines; extract complex branches. A long function has too many reasons to change and cannot be read at once.

Group: Clean code. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Function length limit: functions remain under 100 lines; extract complex branches.

## Why

A long function has too many reasons to change and cannot be read at once.

## A bad example

```py
def run():  # 300 lines
```

## A good example

```py
def run():
    plan = make_plan()
    return execute(plan)
```

An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
