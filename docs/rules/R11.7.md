# R11.7: Bounded in-memory queues

**Short answer:** Memory queues specify max length and overflow policy. A queue with no bound grows until the process runs out of memory.

Group: State and concurrency. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Bounded in-memory queues: memory queues specify max length and overflow policy.

## Why

A queue with no bound grows until the process runs out of memory.

## A bad example

```ts
const queue = [];
```

## A good example

```ts
const queue = new BoundedQueue({ max: 1000, onFull: 'drop-oldest' });
```
