# R16.5: Production bundle minimization

**Short answer:** DevDependencies not imported in production runtime code. A dev dependency imported in production code is missing in the production image.

Group: Supply chain. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Production bundle minimization: devDependencies not imported in production runtime code.

## Why

A dev dependency imported in production code is missing in the production image.

## A bad example

```ts
import { faker } from '@faker-js/faker';  // in src/
```

## A good example

```ts
import { randomUUID } from 'node:crypto';
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R16.5 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
