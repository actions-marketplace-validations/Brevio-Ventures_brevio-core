# R1.6: Accessible switch geometry

**Short answer:** Inline-flex items-center shrink-0 on toggle tracks. A toggle track without fixed geometry squashes in a flex row and the knob leaves the track.

Group: UI and mobile performance. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Accessible switch geometry: inline-flex items-center shrink-0 on toggle tracks.

## Why

A toggle track without fixed geometry squashes in a flex row and the knob leaves the track.

## A bad example

```tsx
<span className="w-10 h-5 rounded-full" />
```

## A good example

```tsx
<span className="inline-flex items-center shrink-0 w-10 h-5 rounded-full" />
```
