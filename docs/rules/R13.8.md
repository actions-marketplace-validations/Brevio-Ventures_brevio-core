# R13.8: Exception traceback containment

**Short answer:** Sanitize public error responses to avoid leaking paths. A stack trace in a reply shows file paths and internals to the caller.

Group: Observability and logging. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Exception traceback containment: sanitize public error responses to avoid leaking paths.

## Why

A stack trace in a reply shows file paths and internals to the caller.

## A bad example

```ts
res.status(500).send(err.stack);
```

## A good example

```ts
log.error(err);
res.status(500).json({ error: { code: 'internal' } });
```
