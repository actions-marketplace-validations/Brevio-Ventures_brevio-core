# R19.4: Descriptive variable naming

**Short answer:** Avoid single-character variables outside trivial loops. A one letter name tells the reader nothing.

Group: Clean code. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Descriptive variable naming: avoid single-character variables outside trivial loops.

## Why

A one letter name tells the reader nothing.

## A bad example

```ts
const d = Date.now() - s;
```

## A good example

```ts
const elapsedMs = Date.now() - startedAt;
```

- Nothing yet. No `brevio-core` command checks it and no `brief` reminder names it: it is a standing rule for authors and reviewers.

## How to silence it

A person can silence one finding with `brevio-core: ignore R19.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
