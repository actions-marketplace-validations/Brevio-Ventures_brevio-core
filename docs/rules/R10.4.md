# R10.4: Structured error envelope

**Short answer:** Error responses adhere to standard JSON error schema. Every endpoint with its own error shape makes every client write its own parser.

Group: API and network robustness. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Structured error envelope: error responses adhere to standard JSON error schema.

## Why

Every endpoint with its own error shape makes every client write its own parser.

## A bad example

```ts
res.status(400).send('bad');
```

## A good example

```ts
res.status(400).json({ error: { code: 'bad_request', message: 'name is required' } });
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R10.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
