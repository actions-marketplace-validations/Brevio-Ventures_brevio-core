# R17.4: Next/Image usage

**Short answer:** Production UI renders next/image for optimized srcset and layout stability. A plain img has no resizing, no srcset and no reserved space.

Group: React and Next.js patterns. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Next/Image usage: production UI renders next/image for optimized srcset and layout stability.

## Why

A plain img has no resizing, no srcset and no reserved space.

## A bad example

```tsx
<img src="/a.png" />
```

## A good example

```tsx
<Image src="/a.png" alt="" width={400} height={300} />
```
