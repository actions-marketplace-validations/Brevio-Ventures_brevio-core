# R15.7: Skeleton loader transition

**Short answer:** Loading states use layout-preserving skeletons to avoid CLS. A spinner that is replaced by content shifts the layout and hurts CLS.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Skeleton loader transition: loading states use layout-preserving skeletons to avoid CLS.

## Why

A spinner that is replaced by content shifts the layout and hurts CLS.

## A bad example

```tsx
{loading && <Spinner />}
```

## A good example

```tsx
{loading ? <TableSkeleton rows={5} /> : <Table rows={rows} />}
```
