# R15.6: Empty state affordance

**Short answer:** Data tables and lists display actionable empty state message. An empty table with no message looks broken.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Empty state affordance: data tables and lists display actionable empty state message.

## Why

An empty table with no message looks broken.

## A bad example

```tsx
{rows.map(Row)}
```

## A good example

```tsx
{rows.length ? rows.map(Row) : <Empty action={<AddButton />} />}
```
