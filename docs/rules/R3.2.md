# R3.2: Monetary integer representation

**Short answer:** Store money as integer minor units (cents) + currency. A float cannot hold 0.1 exactly, so sums of money drift by a cent.

Group: Billing and money. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Monetary integer representation: store money as integer minor units (cents) + currency.

## Why

A float cannot hold 0.1 exactly, so sums of money drift by a cent.

## A bad example

```ts
const price = amountCents / 100;
```

## A good example

```ts
const priceCents = amountCents;  // format when you show it
```

## How it is checked

- `brevio-core scan --surface` checks the lines you add for it; a plain `brevio-core scan` does not.
- `brevio-core brief` and the `brief` tool of `brevio-core mcp` print a one-line reminder of it for a file that matches.

## Measured precision

Not measured. No judged sample of this rule's hits exists.

## How to silence it

A person can silence one finding with `brevio-core: ignore R3.2 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

What the scanner already leaves alone: A file named format* or display*, a component, a function named format*/display* and a line that calls Intl.NumberFormat, toLocaleString or toFixed are not flagged.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
