# R3.5: Transactional outbox

**Short answer:** Persist DB state before enqueuing external side effects. If the process dies between the queue and the database, the outside world and your data disagree.

Group: Billing and money. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Transactional outbox: persist DB state before enqueuing external side effects.

## Why

If the process dies between the queue and the database, the outside world and your data disagree.

## A bad example

```ts
await queue.send(msg);
await db.insert(row);
```

## A good example

```ts
await db.insert(row);
await queue.send(msg);
```
