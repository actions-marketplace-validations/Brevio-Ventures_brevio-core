# R12.1: Event listener teardown

**Short answer:** AddEventListener in useEffect/components pairs with removeEventListener. A listener that is never removed keeps the component alive and fires after it is gone.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Event listener teardown: addEventListener in useEffect/components pairs with removeEventListener.

## Why

A listener that is never removed keeps the component alive and fires after it is gone.

## A bad example

```ts
useEffect(() => { window.addEventListener('resize', f); }, []);
```

## A good example

```ts
useEffect(() => { window.addEventListener('resize', f); return () => window.removeEventListener('resize', f); }, []);
```
