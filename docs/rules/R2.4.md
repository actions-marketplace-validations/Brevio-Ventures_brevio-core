# R2.4: Raw-body webhook verification

**Short answer:** Verify HMAC against raw request text before JSON parse. Parsing the JSON first changes the bytes, so the signature no longer matches and a forged call can pass.

Group: Security and tenancy. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Raw-body webhook verification: verify HMAC against raw request text before JSON parse.

## Why

Parsing the JSON first changes the bytes, so the signature no longer matches and a forged call can pass.

## A bad example

```ts
const body = await req.json();
verifySignature(body, sig);
```

## A good example

```ts
const raw = await req.text();
verifySignature(raw, sig);
const body = JSON.parse(raw);
```

## How it is checked

- `brevio-core scan --surface` checks the lines you add for it; a plain `brevio-core scan` does not.
- `brevio-core brief` and the `brief` tool of `brevio-core mcp` print a one-line reminder of it for a file that matches.

Not measured. No judged sample of this rule's hits exists.

## How to silence it

A person can silence one finding with `brevio-core: ignore R2.4 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
