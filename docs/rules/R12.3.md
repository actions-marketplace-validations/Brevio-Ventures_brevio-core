# R12.3: Stream disposal hygiene

**Short answer:** Open readable/writable streams explicitly call close() or pipe safely. A stream that is not closed keeps its file or socket open.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Stream disposal hygiene: open readable/writable streams explicitly call close() or pipe safely.

## Why

A stream that is not closed keeps its file or socket open.

## A bad example

```ts
const s = fs.createReadStream(p);
```

## A good example

```ts
const s = fs.createReadStream(p);
s.on('end', () => s.close());
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R12.3 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
