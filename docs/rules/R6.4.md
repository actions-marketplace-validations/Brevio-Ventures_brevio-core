# R6.4: Hermetic test state isolation

**Short answer:** Isolate DB/state paths per test in setUp/addCleanup. Tests that share a database or a state folder pass or fail depending on their order.

Group: Testing and hermeticity. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Hermetic test state isolation: isolate DB/state paths per test in setUp/addCleanup.

## Why

Tests that share a database or a state folder pass or fail depending on their order.

## A bad example

```ts
const path = '/tmp/state.json';
```

## A good example

```ts
const path = join(mkdtempSync(join(tmpdir(), 't-')), 'state.json');
```
