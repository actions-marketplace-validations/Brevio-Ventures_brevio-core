# R3.1: Idempotent webhook processing

**Short answer:** Deduplicate event_id with monotonic state transitions. Gateways send an event more than once. Without a check the customer is charged or upgraded twice.

Group: Billing and money. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Idempotent webhook processing: deduplicate event_id with monotonic state transitions.

## Why

Gateways send an event more than once. Without a check the customer is charged or upgraded twice.

## A bad example

```ts
await applyEvent(event);
```

## A good example

```ts
if (await seen(event.id)) return;
await applyEvent(event);
await markSeen(event.id);
```

An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it.
