# R18.5: No click handlers on non-interactive elements

**Short answer:** A div with onClick and no role is flagged. A div with a click handler is not a button for the keyboard or a screen reader.

Group: Accessibility (WCAG 2.1 AA). Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

No click handlers on non-interactive elements: a div with onClick and no role is flagged.

## Why

A div with a click handler is not a button for the keyboard or a screen reader.

## A bad example

```tsx
<div onClick={open}>Open</div>
```

## A good example

```tsx
<div onClick={open} role="button" tabIndex={0}>Open</div>
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R18.5 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

What the scanner already leaves alone: A div with role= after its onClick on the same line is not flagged.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its check in the rule code of the package. That is a code change and is reviewed like one.
