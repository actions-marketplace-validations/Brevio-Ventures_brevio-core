# R15.8: Recoverable 404 navigation

**Short answer:** Not-found pages provide search and home navigation links. A dead end 404 loses the visitor.

Group: Error boundaries and fallback rendering. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Recoverable 404 navigation: not-found pages provide search and home navigation links.

## Why

A dead end 404 loses the visitor.

## A bad example

```tsx
export default () => <h1>404</h1>;
```

## A good example

```tsx
export default () => <NotFound links={['/', '/search']} />;
```

## How to silence it

A person can silence one finding with `brevio-core: ignore R15.8 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.
