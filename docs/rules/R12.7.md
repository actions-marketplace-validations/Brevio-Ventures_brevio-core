# R12.7: Temp file deterministic deletion

**Short answer:** Scratch files in /tmp register unlink in finalizer. Scratch files that are never deleted fill the disk.

Group: Memory and resource leaks. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Temp file deterministic deletion: scratch files in /tmp register unlink in finalizer.

## Why

Scratch files that are never deleted fill the disk.

## A bad example

```py
tmp = '/tmp/work.json'
```

## A good example

```py
with tempfile.TemporaryDirectory() as d:
    tmp = os.path.join(d, 'work.json')
```
