# Support

brevio-core is maintained on a best-effort basis by a small team. There is no paid support and no service level here.

| You have | Go to |
|---|---|
| A question, an idea, or "how do I" | [GitHub Discussions](https://github.com/Brevio-Ventures/brevio-core/discussions) |
| A crash or a command that does not do what its help says | An issue, with the "Bug" form |
| A finding on code that is correct | An issue, with the "False positive" form |
| A mistake agents repeat that a rule could catch | An issue, with the "New rule" form, or a Discussion first |
| A hit on the precision page that you think was judged the wrong way | An issue, with the "Dispute a precision verdict" form |
| A security problem | Privately, as [SECURITY.md](SECURITY.md) says; never in a public issue |

We aim to give a first response within 7 days. A fix or a decision can take longer, and we say so in the thread.
Issues are for bugs; questions opened as issues are moved to Discussions.
